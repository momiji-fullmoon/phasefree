熊本2026 インフラ初動AI（配布版）つかいかた

フェーズフリー型自治体防災AI実証事業（提案用デモ）。熊本県南部を対象に、平時の点検管理と令和8年熊本地震（2026-07-28 16:27 假想・M7.1）の発災後対応を、同じ資産IDとデータ基盤で再現します。

1. はじめに（必ずお読みください）

  • これは提案・議論用のデモです。地図・画面・台帳上の被害・点検結果には合成データ（仮）を含みます。実データ（公表資料・橋梁台帳・地震観測）と合成の区別は、アプリ内の「データ基盤」タブでA/B/Cの取得区分と出典一覧から必ず確認してください。
  • 画面の説明・数値は実在の施設の状態を示したものではありません。行政判断の根拠としてはそのまま使用しないでください。
  • 操作履歴（実施記録など）はこのPCのブラウザに保存されます。サーバーに送信されません。

2. 起動まで（およそ3分）

STEP 1ZIPファイルを右クリック（Mac: ダブルクリック／Windows: すべて展開）してフォルダごと丸ごと解凍します。
※解凍したフォルダの中にある以下の相対位置は絶対に変えないでください（zip内の直接実行も不可）:
index.html ＋ kumamoto_event_data/（発災後アーカイブ219MB） ＋ vendor/（地図ライブラリ）
STEP 2index.html をダブルクリックして開きます。
推奨: Google Chrome / Microsoft Edge / Safari の最新版（iPhone等小型端末では未検証です）。
STEP 3画面上部の「AIに指示」タブに 例文（下「5. 例示プロンプト」）を入力し、画面が動くことを確認します。
うまく動かない時は README.md（開発者向）の「実行」、docs/phase-free-p1.md のP1操作ノートも参照できます。

4. 実施記録の入力と持ち帰り（「計画・業務」タブ）

  • 「計画・業務」→ 点検記録の入力で、完了・未実施・追加調査を班ごとに登録できます。未実施理由・損傷の有無も残ります。
  • 入力した実施記録は、記録・履歴ナンバー付きで保存され、災害前の点検記録（平時）と発災後の確認を時刻で分けて扱います。
  • 保存先はこのPCのブラウザだけです。別PCや別ブラウザへ移す場合は「JSON書出し」で1ファイル（約7MB）にして持ち運び、「JSON読込み」で復元します。
  • ブラウザの「ようこそで許可」が出た場合（ローカル保存の許可）は許可しておくと自動保存が効きます（不要なら確認メッセージそのままで図も動作します）。

  • 「公表された被害速報と、対応する橋梁の根拠を見せて」（根拠タブへ誘導）

  • 「発災後に取得した実データの一覧を見せて」（データ基盤タブに出典索引が表示）

6. よくあるご質問

index.html をダブルクリックしても動かない(1) ZIPの中身が一部しか解凍されていない（特に kumamoto_event_data が無い）
(2) index.html と kumamoto_event_data/ の相対位置を変えて移動した → フォルダ構成を保ったまま移動
地図や写真が表示されない上と同じくフォルダの配置です。 インターネット接続を切っている場合も（公式同梱の地図・データで）動作します。
PCやブラウザを変えたいGitHub Pages上の公開版（https://momiji-fullmoon.github.io/phasefree/）でも同一のデータ・画面が動きます。
ブラウザ内の保存内容（実施記録など）はサイトごと（ローカル／公開サイト）に独立しているので、移すときは「計画・業務」タブの JSON書出し → 読込み を使います。
Claude で操作・提案を自動化したいこのzipのローカルAI（簡易ルール）ではなく、claude.ai の Artifact 上に本キットを読み込ませるとClaudeによる計画判断の補助が有効になります。人の最終確認・承認は画面操作で必須という設計です。
配布・再配布このzipをそのまま丸ごとお渡しください（中身のフォルダ構成は変更しないでください）。データの区分・出典はすべて「データ基盤」タブで確認できます。

7. データと出典

  • 実データ（公表資料・強震記録・衛星画像・橋梁台帳など）はファイル単位で kumamoto_event_data/ に保存しており、「データ基盤」タブの出典索引（209件／登録223項目）から原本URLと保存分（「開く」ボタン）が確認できます。
  • 合成データ（被害想定・SNS・点検初期値・予算など）はアプリ内の説明と出典表示で明示しています。
  • 未確定事項（自治体名称・正式な計画本文・業務手順の適用版）は「計画・業務」タブの資料カードに「未確認」と表示されます。

本キットの主眼＝「同じ研修・打ち合わせの上で、平時と災害時を重ねて議論できる状態にしておくこと」です。担当者・自治体・関係者の方に、このzipのままお渡しください。—— 熊本2026 インフラ初動AI プロジェクト
